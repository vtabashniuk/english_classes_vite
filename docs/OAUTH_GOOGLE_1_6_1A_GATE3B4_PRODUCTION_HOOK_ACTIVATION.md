## 3. Immediate smoke checks (Hook ON)

**B. Authorized NEW email invitation (critical positive test):** from a real authorized teacher in Production CRM invite a **new** Gmail +alias controlled by you (`username+crm-gate3b4-allow-<unique>@gmail.com`). Send once only. Verify toast, exactly one email in Gmail, correct Production `/set-password` redirect. Before installing the password run the read-only SQL below. It must show the ticket consumed by the Hook, not merely revoked by the server. The invite must create exactly one Auth user, student profile and active teacher link. The token VALUE in Auth metadata must be scrubbed. Do NOT leak the invite URL/ticket in chat or logs.

SQL to paste only into cloud SQL Editor (`main / PRODUCTION`) and **replace the placeholder with the allowed test alias** without editing or committing a repository file:

```sql
BEGIN TRANSACTION READ ONLY;
WITH target AS (
  SELECT lower(btrim('REPLACE_WITH_ALLOWED_TEST_GMAIL_ALIAS')) AS email
),
usr AS (
  SELECT u.id, u.raw_user_meta_data
  FROM auth.users u, target t WHERE lower(u.email) = t.email
),
stu AS (
  SELECT p.id FROM public.profiles p
  JOIN usr u ON u.id = p.id WHERE p.role = 'student'
),
adm AS (
  SELECT a.consumed_at, a.revoked_at, a.expires_at
  FROM crm_private.email_invitation_admissions a, target t WHERE a.email = t.email
)
SELECT
 (SELECT count(*) FROM usr) AS auth_users,
 (SELECT count(*) FROM stu) AS student_profiles,
 (SELECT count(*) FROM public.teacher_students ts
    JOIN stu s ON s.id=ts.student_id WHERE ts.is_active = true) AS active_teacher_links,
 (SELECT count(*) FROM adm) AS issued_tickets,
 (SELECT count(*) FROM adm WHERE consumed_at IS NOT NULL) AS consumed_tickets,
 (SELECT count(*) FROM adm WHERE revoked_at IS NOT NULL) AS revoked_tickets,
 (SELECT count(*) FROM adm WHERE consumed_at IS NULL AND revoked_at IS NULL
      AND expires_at > now()) AS live_tickets,
 (SELECT count(*) FROM usr
      WHERE length(coalesce(raw_user_meta_data ->> 'crm_email_invite_ticket', '')) > 0) AS auth_users_with_ticket_value;
COMMIT;
```

Expected if this is the first invite for the brand-new alias: `1,1,1,1,1,0,0,0`. A `revoked_tickets=1` and `consumed_tickets=0` means the Hook did not consume the ticket — **NOT PASS**, even if a user was created. Failed invitation or unexpected counts = STOP; inspect Logs, don't retry blindly.
